# SkillHUB

Єдиний застосунок (PWA) для GitHub Pages: **Асистент** (пошук, резерви, SkillHUB, опції) та **Академія**
(навчання, тести, статистика команди). Дані та вхід — через Google Apps Script (`Код.js`, лежить у таблиці).

## Структура

```
index.html            єдина сторінка (Асистент + розділ «Академія» #academyApp)
Education.html        заглушка-перенаправлення на ./#academy (старі закладки)
manifest.json         PWA-маніфест
sw.js                 service worker: офлайн-кеш (генерується tools/build_sw.py)
css/
  fonts.css           @font-face (шрифт Inter, власні файли)
  assistant.css       стилі Асистента
  academy.css         стилі Академії (усі селектори під #academyApp)
js/
  core/config.js      адреса API, імена сховищ, папка іконок кнопок
  core/storage.js     IndexedDB (спільне сховище)
  assistant/          логіка Асистента
  academy/            логіка Академії (вхід, токен, тести, черга відправки)
  vendor/             сторонні бібліотеки (chart.umd.js)
assets/
  brand/              іконка застосунку, логотип
  fonts/              Inter (woff)
  achievements/       картинки відзнак: <код>.webp (код з таблиці)
  icons/
    ui/               іконки інтерфейсу (навігація, обране, знижка…)
    skillhub/         ← іконки кнопок SkillHUB; ім'я файлу вказується в таблиці
    academy/          іконки розділу «Академія»
    archive/          невикористовувані (збережено)
tools/build_sw.py     оновлення списку офлайн-файлів і версії sw.js
```

## Кнопки SkillHUB з таблиці
Лист «кнопки SkillHUB»: колонка A — **ім'я файлу з `assets/icons/skillhub/`** (напр. `calculator.svg`) або емодзі,
B — назва, C — опис, D — дія: посилання, `Academy` (відкрити Академію), `Calculator_kloch`, `--`, `%`, `@@`.
Щоб додати нову іконку — покладіть svg у `assets/icons/skillhub/` і впишіть її ім'я в таблицю.

## Реліз
1. Змінили файли → `python3 tools/build_sw.py` (оновить кеш і версію).
2. `git commit && git push`.

## Безпека
Паролі перевіряє сервер (Apps Script): токени, блокування підбору, права за роллю, один пристрій.
У репозиторії та на пристрої немає паролів. Деталі — у меню таблиці «Головне меню → Безпека».
